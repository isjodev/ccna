Collections of notes and scripts created during CCNA studies. Context for
anyone who may stumble across these resources: These are personal notes and
resources I've created while studying for the CCNA certification. I have a
non-trivial amount of computational training, have worked in telecom, and have
been writing software as a hobbyist and using linux for the better part of a
decade. Do not use these materials to learn these technologies unless you
already have a strong computational foundation.

I can't in good conscience recommend this (YMMV), but if you want to get a
strong sense of what computers are and how they work, spend a year learning C,
get a copy of CLRS or The Algorithm Design Manual, and read The Linux Kernel
Documentation. Break stuff, learn how to fix it, don't get distracted
distro-hopping, and stick with it. After that you'll be able to pick up any
technology you need to learn on the fly. The point is to learn how to build
mental models of complex systems, build generalized schemas you can integrate
new information into, learn to carefully read documentation (unless you want to
waste a day trying to compile some obscure astronomical simulation software for
a unsupported architecture instead of just reading the first paragraph of the
build instructions), and learn enough to know how little you know and where and
how to look for the information you don't have. Read K&R, it's some of the best
technical writing I've ever read.

Chiefly using Jeremys IT Lab CCNA course, with Manning Publications Acing The
CCNA Exam books. Google-Fu.
