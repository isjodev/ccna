Commands
- enable: switches to privileged exec mode
- configure terminal / conf t: enter global configuration mode
- enable password (password): enables and encrypts crackable
	plain text passwords.
- service password-encryption: encrypts current and future
	passwords without affecting enable secret.
- enable secret: enables password for privileged exec mode.
